# 智码对接 heng-agent：要在智码里做的事

给智码（AICoder）的开发会话看的清单：把 heng-agent 加成智码里的一种 CLI，用智码管理的 API Profile 启动它。
heng-agent 这边需要的接口都已经有了，**本清单里的改动都在智码项目里**。协议细节（ACP 的消息格式、权限确认、
会话列表）见同目录的 [acp.md](acp.md)，这里不重复。

## 1. 两种接法

| 接法 | 启动命令 | 适合 |
|---|---|---|
| 任务终端里直接运行（交互界面） | `heng-agent --workdir <项目目录> --session-id <智码预先分配的 id>` | 和 Claude Code、Codex 一样，在智码的终端标签页里用 |
| 智码自己的对话界面（ACP） | `heng-agent --acp` | 智码画界面，heng-agent 只做智能体；见 acp.md |

两种都用下面同一套环境变量传服务商。检测有没有装、怎么装、程序在哪，见 acp.md 第 0 节。

**预先分配会话 id**（0.5.1 起）：`--session-id <id>` 用指定的 id 开新会话，会话文件就叫 `<id>.json`——
和 Claude Code 一样进 `PREALLOC_CLI_ID_TOOLS`，不用事后扫目录猜「刚开的是哪个会话」。id 只能用字母、数字、
点、下划线、短横（UUID 可以），最长 128；id 已在用时报错退出（不会悄悄接到旧会话上），接着聊用 `--resume <id>`；
不能和 `--resume` 一起用。用户没发任何消息就退出时不会生成会话文件。

## 2. API Profile → 环境变量

智码启动 heng-agent 时，把选中的 Profile 转成环境变量（**只放进这个子进程的环境里**）：

| 智码 Profile 字段 | heng-agent 环境变量 | 怎么转 |
|---|---|---|
| `baseUrl` | `HENG_AGENT_BASE_URL` | 原样；设了它才启用这一组变量 |
| apiKey（智码内部取，AI 拿不到的那份） | `HENG_AGENT_API_KEY` | 原样 |
| `model` | `HENG_AGENT_MODEL` | **必填**。去掉 Claude Code 专用的后缀，如 `claude-fable-5-1[1m]` → `claude-fable-5-1`（`[1m]` 是 Claude Code 自己的写法，heng-agent 会原样发给服务，多半被当成不存在的模型）；为空时让用户选一个，别空着启动（heng-agent 会报错退出） |
| `keyAuthType` | `HENG_AGENT_AUTH` | `auto` → `auto`；用 `ANTHROPIC_AUTH_TOKEN` 的 → `bearer`；用 `ANTHROPIC_API_KEY` 的 → `x-api-key` |
| `toolId` | `HENG_AGENT_PROTOCOL` | `claude-code` 的 Profile → `anthropic`；`codex` 等 OpenAI 协议的 → `openai` |

**`authType` 为 `oauth` 的 Profile（如 `anthropic-oauth`，Claude 订阅账号登录）不能给 heng-agent 用**：在给 heng-agent
选 Profile 的列表里隐藏它们，或者置灰并写明「订阅账号只能用于官方 Claude Code」。原因：订阅账号的登录令牌只给官方客户端用，
第三方读出来调接口违反 Anthropic 的服务条款，可能导致封号。用户想用订阅额度，就在智码里开 Claude Code 会话。
Codex 的 ChatGPT 登录同理。

设了这组变量后：

- 这个服务商只在这次运行里用，**不写进** heng-agent 的配置文件；用户在 heng-agent 里配好的服务商不受影响；
- heng-agent 不弹首次运行引导（看到 `HENG_AGENT_BASE_URL` 就跳过）；
- 交互界面里 `/provider` 列表中它叫 `env`，用户还能切回自己配的其它服务商。

不设这组变量，heng-agent 就用用户自己在 heng-agent 里配的默认服务商，和用户在系统终端里运行一样。

## 3. 安全要求

- 密钥**只走环境变量**，不要拼进命令行参数（会出现在进程列表、任务管理器里），也不要写进 heng-agent 的配置文件。
- 不要把 `HENG_AGENT_*` 设进智码自己的全局环境，或用户的系统环境：只给 heng-agent 这一个子进程。
- 别设 `HENG_AGENT_HOME`，除非确实要一套独立的数据：不设时会话、记忆、信任记录和用户在系统终端里用的是同一份。

## 4. 会话索引（智码的「历史会话」「搜索会话」）

heng-agent 的会话存在数据目录下，每个会话一个 JSON 文件，智码可以只读地扫描它们建索引：

- 位置：`<数据目录>/sessions/<目录名>-<路径 sha1 前 10 位>/<会话 id>.json`。数据目录：正式版 `~/.heng-agent`，开发版
  `~/.heng-agent-dev`，设了 `HENG_AGENT_HOME` 就是它。
- 会话 id 形如 `20261028-143548-95be5f`（开始时间 + 随机后缀）。
- 字段：`format`（现在是 1）、`workdir`（项目目录）、`messages`（Anthropic Messages 格式的对话）、`usage`
  （`input_tokens`、`output_tokens`、`cache_read_tokens`、`cache_write_tokens`）、`usage_by_model`（按模型分的用量）、
  `title`（用户起的名字，可能没有）。
- 恢复会话：交互界面 `heng-agent --workdir <目录> --resume <会话 id>`；ACP 用 `session/load`（见 acp.md 第 6 节）。
- 只读，别改这些文件：heng-agent 写文件时是先写临时文件再整体替换，读到半截文件的概率很小，读失败跳过即可。

## 5. MCP：把智码的 MCP 服务挂进 heng-agent

和智码对其它 CLI 一样写进 heng-agent 的用户配置 `<数据目录>/config.json`（数据目录见上一节），键名 `mcp_servers`
（也认 Claude Code 的 `mcpServers`，两个都有时同名的以 `mcp_servers` 为准）：

```json
{
  "mcp_servers": {
    "aicoder":    {"command": "C:\\...\\aicoder-mcp.exe", "args": ["--stdio"], "env": {"TOKEN": "…"}, "timeout": 60},
    "aicoder-dev": {"type": "http", "url": "http://127.0.0.1:7420/mcp", "headers": {"Authorization": "Bearer …"}}
  }
}
```

- 本地服务写 `command` / `args` / `env`；HTTP 服务写 `url` / `headers`（Streamable HTTP；老式 SSE 不支持）。`timeout` 秒，默认 60。
- 字符串里可以写 `${变量}` / `${变量:-默认值}`，启动时用环境变量展开。
- 🔴 这个文件里还有用户自己的服务商、密钥与设置：**只增删改 `mcp_servers` 里智码自己的那几项**，其余原样保留；
  文件不存在就新建。写完 heng-agent 下次启动生效（用户级的服务不用信任确认）。
- 用户在 heng-agent 里输入 `/mcp` 能看到这些服务及连接情况。

## 6. 智码给 Claude Code 注册的钩子

heng-agent 兼容 Claude Code 的钩子：默认会读 `~/.claude/settings.json` 里的钩子并执行。智码给 Claude Code 注册的
钩子（如 SessionStart 时把会话 id 记进 `.aicoder-claude-sessions.jsonl` 的那条）因此在 heng-agent 里也会触发，
可能把 heng-agent 的会话记成 Claude 的。启动 heng-agent 时要避开这些钩子（具体做法在接入终端模式时定）；
用户自己的 heng-agent 配置里可以用 `settings.claude_hooks_skip`（命令里含有这些文字的 Claude 钩子跳过）。

## 7. 做完怎么验证

1. 用一个 `api_key` 类型的 Profile 启动，在 heng-agent 里输入 `/status`：服务商一行应显示 `env` 与 Profile 里的模型；
   输入 `/doctor` 看「服务商连接」那项是否通过（会真连一次服务，只拉模型列表，不消耗对话额度）。
2. 发一句话，确认能正常回答；底部状态栏第一行显示模型名，用中转站的还会显示额度（如「已用 $71.98」）。
3. 退出后检查 `~/.heng-agent/config.json`：不应出现这个 Profile 的密钥。
4. 选一个 `oauth` 类型的 Profile：智码应当不让它启动 heng-agent，并说明原因。
5. 智码的会话列表里能看到刚才那次会话，点开能恢复。
